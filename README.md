# WO... — A Poetic Novel

This repository contains the static website for the book "WO..." by Yash Kumar Prajapati.

Contents:
- `INDEX.HTML` — main site
- Assets — images and media used by the site (place book cover image in the site root as `BOOK COVER MNE 88143.png`)

Deployment
- Create a GitHub repository and push this code.
- For a static site you can enable GitHub Pages (Settings → Pages) and select the `main` branch and `/ (root)` folder to publish.

How to push from this folder (run locally):

```bash
cd "d:/MY BOOK/BOOK WERBSITE"
# add a remote (replace <your-repo-url> with your GitHub repo HTTPS or SSH url)
# git remote add origin <your-repo-url>
# git push -u origin main
```

If you prefer SSH, add your SSH key to GitHub and use the SSH URL when adding the remote.

If you want, I can initialize a local git repo and create the first commit here; after that you'll only need to add the remote and push.
